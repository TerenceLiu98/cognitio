# Paper Page

Use YAML frontmatter with `title`, `type: paper`, `authors`, `year`, stable paper identifiers when present, and focused tags. The body must contain: TL;DR, Research Question, Motivation, Contributions, Method, Experiments, Limitations, Related Concepts, and Related Papers. Add `[[index|Library home]]` once so every Paper is connected to the library root in Quartz's graph.

Name the file with a stable lowercase kebab-case slug. Prefer the paper's canonical title over a local PDF filename.
